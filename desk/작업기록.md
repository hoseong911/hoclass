
## 예순여섯째 — 바로가기 고치기
설정 창 > 바로가기에서 **더하기와 지우기만 되고 고치기는 아예 없었다**. 줄마다 「고치기」
단추를 두고, 누르면 아래 넣는 칸이 그 사이트 내용으로 채워진다(이름·주소·아이콘 모두).
단추 글씨는 「추가」에서 「저장」으로, 블록 제목은 「사이트 추가」에서 「사이트 고치기」로
바뀌고, 옆에 「그만두기」가 생긴다. 저장하면 **같은 자리에 되쓴다**(id 를 지켜서 새로
생기지 않는다). 고치는 중에 그 줄을 지우면 넣는 칸도 같이 비운다.
시험(desk.test.js)에 고치기·그만두기 두 갈래를 더했다. 줄 안 단추가 둘이 돼서
지우기 시험은 첫 단추가 아니라 글씨로 고르도록 바꿨다.

## 예순아홉째 — 할 일 네 칸을 급한 순서대로 강조
선생님 지시: "4사분면을 각각 강조해주고 싶다는거야. 올 강조하면 눈에 안띄니까 필요한 순대로".
전에는 네 칸이 테두리, 모서리, 틈이 다 같고 칸 이름 글자색 하나만 달랐다. 이제 **네 가지를
같은 순서로 같이 내린다**: 바탕(첫 칸만 레드 반투명), 테두리(레드, 진한 회색, 연한 회색,
연한 회색), 칸 이름(레드 700, 네이비 600, 보조 회색, 옅은 회색), 할 일 글씨(굵게, 기본,
보조 회색, 옅은 회색).
**바탕을 칠하는 것은 첫 칸 하나뿐이다.** 둘 이상이면 강조가 사라진다. 시험이
`.q-cell.q0 { background:` 만 있는지 세어 지킨다(`checkTodoCells`). 쓴 색은 레포가 이미
「고른 것」과 「지금 교시」에 쓰는 `--accent-fade` 하나라 새 색을 늘리지 않았다.
`.q-cell` 기본 규칙에는 바탕이 없어야 한다는 옛 시험은 그대로 두고(그 자리에 칠하면 네 칸이
다 칠해진다), 칸별 규칙만 세는 검사를 더했다. 끌어 놓는 자리 표시(`.q-cell.over`)는 전처럼
바탕 한 단으로 알리므로 첫 칸 위에서는 그 바탕이 잠깐 덮인다.
바탕화면 위젯도 같은 `desk.css` 를 보므로 같이 바뀐다.

## 일흔째 — 나이스 시간표 받아오기 점검과 고침
선생님 지시: "나이스에서 시간표 받아오는거 확인 좀 해봐". 실제 나이스를 직접 불러
(인증키 없이, 동양중학교 C10 7181079) 받아지는지 확인했다.
**잘 되는 것**: 학교 찾기(동양중학교 셋이 나온다: 서울 B10, 부산 C10, 인천 E10),
중학교 → `misTimetable` 길 고르기, 하루 시간표 읽기, 과목 거르기, 5x7 만들기.
**고친 것 하나 (실제 버그)**: 나이스에 묻는 학년도(`AY`)를 수첩이 보는 학년도
(`state.year.current`)로 넘기고 있었다. 수첩을 2027 학년도로 갈아 둔 채 2026년 11월에
받아오면 나이스가 **0칸**을 주고 화면은 "과목 이름을 확인해 주세요"라는 엉뚱한 까닭을
보인다. 받아오는 **그 주의 학년도**(`academicYear(now)`)로 묻게 고쳤다. 시험이 지킨다
(가짜 나이스가 받은 인수를 `neisArgs` 에 적어 두고 견준다. 옛 코드로 되돌려 실패하는 것까지 확인).
**고친 것 둘**: 한 칸도 못 찾았는데 자료가 잘린 것이었으면(`tt.short`) 과목 이름을
탓하지 않고 "인증키가 없어 1~5교시만 받았습니다"로 알린다.
**못 고친 것(선생님께 여쭐 것)**: ① 인증키가 없으면 나이스가 **다섯 줄만** 주므로
6, 7교시가 통째로 빈다. ② 호출 수가 5일 x 반 개수다(반 셋에 15번). 수업 반이 여덟이면
40번이라 인증키 없이는 일일 횟수에 걸릴 수 있다. 인증키가 있으면 날짜별로 학교 전체를
한 번에 받아 5번으로 줄일 수 있다. 둘 다 인증키를 넣으면 풀린다.

## 일흔하나째 — 주간 시간표가 온통 "3-1" 로 채워지던 까닭
선생님이 화면을 보여 주셨다: 주간 시간표 35칸이 전부 "3-1" 이었다.
**까닭**: 설정의 나이스 탭 **「내 과목」 칸이 비어 있었다.** `neis.js` 의 `loadMyWeek` 는
`if (want && !x.subject.includes(want)) continue;` 로 거르는데, 과목이 빈 글자면 **거르기가
통째로 꺼져** 그 반의 모든 교시가 들어오고, `if (!tt[day][p])` 때문에 **수업 반 목록의 첫 반**이
빈칸을 다 먹는다. 실제 나이스로 재현했다(과목 빈칸 → 25칸이 다 "3-1", 과목 "사회" → 3칸).
**고침**: 과목이 비면 받아오지 않고 "내 과목을 먼저 넣고 저장해 주세요"로 멈춘다.
가짜 나이스도 과목 없이 부르면 던지게 했다(관대한 가짜는 거짓 안심만 준다).
시험은 과목을 비운 채로 시작해 막히는 것을 보고, 그다음 과목을 넣고 받아온다.
**선생님이 하실 일**: 설정 > 나이스 > 내 과목에 과목 이름(역사, 사회)을 넣고 저장한 뒤
[이번 주 시간표] 를 다시 누른다. 지금 들어 있는 "3-1" 35칸은 그때 덮인다.

## 일흔두째 — 과목마다 가르치는 반이 다른 경우
선생님 말씀: "나는 사회 역사 다 하고 사회는 3~6반 역사는 1~6반 하는데?"
전에는 **과목 칸 하나, 반 목록 하나**였다. 그래서 역사와 사회를 같이 넣으면 1반, 2반 사회처럼
**남이 가르치는 칸까지** 들어왔다(나이스는 누가 가르치는지는 안 알려 주고 과목만 알려 준다).
선생님이 고르신 길: **과목 줄을 여러 개**.
- `state.neis.subjects = [{ name, classes: ["3-1", ...] }]`. 설정 > 나이스 > **내 과목** 묶음에서
  [과목 추가] 로 줄을 늘리고, 줄마다 과목 이름 한 칸과 **반 고르개**(`.cpick`)를 둔다.
  새 줄은 수업 반과 담임 반이 다 켜진 채로 시작하고, 안 가르치는 반을 끄면 된다.
  과목 이름은 커서가 빠질 때, 반은 누르는 즉시 저장된다(따로 저장 단추를 두지 않는다).
- `neis.js` 의 `loadMyWeek(school, ay, sem, monday, subjects, key)` 가 줄마다 돈다.
  **과목 이름이 빈 줄은 건너뛴다**(빈 과목은 거르기를 꺼서 첫 반이 35칸을 다 먹는다).
  과목 줄끼리 반이 겹치므로 **같은 날 같은 반은 한 번만 받는다**(`got` Map).
- 옛 자료(`subject` 한 칸)는 나이스 탭을 열 때 줄 하나로 옮기고 수업 반을 다 켜 둔다.
- 담임 반도 반 후보에 넣는다. 담임 반에서도 제 과목을 가르친다.
**실제 나이스로 확인**(동양중 C10, 역사 3-1~3-6, 사회 3-3~3-6): 13칸이 반별로 맞게 들어오고
나이스 호출은 50번이 아니라 **30번**(반 여섯 x 5일)이었다. 겹치는 반을 두 번 받지 않는다.
**남은 한계**: 인증키가 없어 1~5교시만 온다(`short`). 6, 7교시는 인증키를 넣어야 채워진다.

## 일흔셋째 — 학년이 섞인 경우
선생님 물음: "근데 3학년이 아니면?" 과목 줄의 반 고르개는 **학년도 설정의 수업 반과 담임 반**에서
나온다. 반은 "3-1" 처럼 학년을 품은 글자라 1학년, 2학년도 그대로 들어간다.
실제 나이스로 확인했다(역사 3-1~3-4, 사회 1-1~1-4 → 11칸이 학년별로 맞게 들어옴).
고친 것은 하나: 학년이 섞이면 **적은 차례가 뒤죽박죽**이라 고르개를 학년, 반 차례로 세운다.
**선생님이 하실 일**: 설정 > 학년도 설정 > 수업 반에서 [반 더하기] 로 가르치는 반을 다 넣는다.
거기 있는 반만 과목 줄의 고르개에 나온다.

## 일흔넷째 — 단추 말을 추가, 삭제로 맞춤
선생님 지시: "더하기 지우기 이런거 말고 삭제 추가 이렇게 하면 안돼?"
**말을 둘로만 쓴다: 「추가」, 「삭제」.** 더하기, 지우기, 빼기는 다 걷었다.
- 장 더하기 → 장 추가, 이 장 지우기 → 장 삭제, 반 더하기 → 반 추가, 이 반 빼기 → 반 삭제
- 이 항목 삭제 → 삭제, 기록 추가 / 수업 기록 추가 / 업무 추가 → 추가
- 완료 항목 지우기 → 완료 항목 삭제 (index.html)
**무엇을 추가하는지는 한 화면에 둘 이상 설 때만 앞에 붙인다.** 학년도 설정 탭에는 학년도
추가와 반 추가가 같이 서므로 둘 다 이름을 남겼고, 화면 탭의 장 추가/장 삭제도 짝이라 남겼다.
묶음 안에 하나뿐인 자리는 「추가」, 줄 끝은 「삭제」다.
**안 한 것**: 글자를 떼고 아이콘만 두는 길(선생님이 같이 말씀하신 둘째 안)은 두지 않았다.
수첩은 칸이 작아지면 통째로 줄어드는데(`--z`), 아이콘만 남기면 무엇을 지우는 단추인지
알 길이 `title` 밖에 없어 손가락 기기에서 확인이 어렵다. 원하시면 그때 바꾼다.

## 일흔다섯째 — 담임 반 창체 시간을 주간 시간표에 넣음
선생님 물음: "월요일 시간표는 왜 없노". 11/9(월)은 학사 일정 **진로테마학습**이라 나이스가 1~5교시를
모두 "진로활동"으로 준다. 내 과목(역사, 사회)으로 거르면 한 칸도 안 남아 하루가 비었다.
선생님 지시: 진로활동 같은 것은 담임 반에 맞춰 보여 주고, **동아리도 임장하니 꼭 넣는다**.
- `loadMyWeek(..., key, homeroom)` 이 담임 반 하루 시간표도 받아, 창체 칸(`CC_RE`: 진로, 자율, 자치,
  동아리, 봉사)을 **빈칸에만** 그 이름 그대로 넣는다. 내 수업이 먼저다. 수학, 영어 같은 교과는 안 넣는다.
- 담임 반이 과목 줄의 반과 겹치면 받아 둔 것을 다시 쓴다(`got`). 겹치지 않으면 하루 한 번 더 부른다.
- 시험 `checkHomeroomCC`: 가짜 fetch 로 진짜 `loadMyWeek` 을 돌린다.
**실제 나이스로 확인**(인천동양중 E10 7331219, 담임 3-6): 월요일 1~5교시가 진로활동으로 찬다.

## 일흔여섯째 — 학년도 탭을 「기본」 설정으로, 학교는 한 곳에서만
선생님 지적(화면을 보여 주심): 학년도 설정 화면이 난잡하다. "이게 가장 기본 설정 아닐까",
"학교 이름은 왜 자꾸 넣는 건데".
- 탭 이름 **학년도 → 기본**(key 는 `year` 그대로). 순서: 학교, 학년도, 담임 반, 수업 반, 자동 잠금.
- **학교**: 학년도 탭의 「학교」 글칸(`state.school`)은 나이스 학교 찾기 칸을 미리 채우는 것 말고
  쓰는 데가 없었다. 지웠고, 나이스 탭의 **학교 찾기를 기본 탭으로 옮겼다**. 나이스 탭은 인증키, 내 과목,
  받아오기만 남는다. `state.school` 자료는 백업 호환으로 남겨 둔다.
- **반 고르개**: 숫자칸 둘(학년, 반)과 "학년" "반" 글자가 좁아 "학/년" 으로 세로로 깨졌다.
  `roomPicker` 로 바꿨다: 1~3학년 단추를 고르면 1~12반 단추가 나오고, 눌러서 켜고 끈다.
  담임 반은 하나만(다시 누르면 담임 아님), 수업 반은 여럿. 고른 반은 아래 글줄로 보인다.
- **즉시 저장**: 누르는 순간 저장한다(나이스 탭과 같게). 맨 아래 「저장」 단추와 form 을 걷었다.
- **회색 상자**: `.set-block` 의 테두리와 회색 바탕을 걷고 위 가는 줄과 여백으로 나눴다(모든 탭 공통).
- 문구 「'학년도 설정'에서」 → 「'기본 설정'에서」.

## 일흔일곱째 — 기본 설정을 다시 짬: 내 정보, 학교에 맞는 반 수
선생님 지적(화면을 보여 주심): "ui 가 엉망이다", "12반까지 굳이 필요 없을 수도", "사용자 설정하는
부분을 만들고 거기서 담임인지 아닌지도". 일흔여섯째 화면은 `.set-state` 의 `flex: 1 1 140px` 가
세로 묶음 안에서 높이 140px 이 되어 빈 데가 크게 났다(직접 찍어 보지 않고 넘긴 탓).
- **내 정보** 묶음: 학교, 학년도, 담임을 왼쪽 이름 오른쪽 값(`.set-line`)으로. 좁으면(480px 아래) 위아래로.
  - 학교: 정했으면 이름과 「바꾸기」만. 찾기 칸은 바꿀 때만 연다. Enter 로도 찾는다.
  - 학년도: 「+ 다음 학년도」 한 번으로 추가(숫자칸 걷음).

## 일흔여덟째 — 시간표 하루 한 번 저절로 받기, 옛 neis.js 가 돌던 까닭, 시간표 탭 정리
선생님 말씀: "다시 받기해도 이럼(월요일이 빔)", "시간표는 자동으로 받게 하는 방법 없나",
"자동으로 받았을 때는 토스트로, 하루에 한 번".
**월요일이 빈 까닭**: 코드는 맞았다(선생님 설정과 인증키로 직접 돌리면 월 1~7교시 진로활동, 화 6교시
동아리활동). 그런데 20:48 저장된 시간표에는 둘 다 없었다 = **브라우저가 옛 neis.js 로 받았다**.
GitHub Pages 는 `Cache-Control: max-age=600` 이고, 서비스워커의 "네트워크 우선"도 그냥 `fetch(req)` 라
브라우저 HTTP 캐시가 10분 묵은 것을 내줬다. desk.js 만 새것, neis.js 는 옛것인 채로 돌 수 있다.
고침: `sw.js` 의 수첩(`/desk/`) 길만 `fetch(req, { cache: 'no-cache' })` (늘 서버에 묻고, 안 바뀌었으면 304).
**저절로 받기**: `fetchWeek()` 로 단추와 같이 쓴다. `autoWeek()` 는 하루 한 번(`state.ttAuto` = 받은 날,
설정에 같이 저장해 기기끼리 되풀이 안 함). **클라우드 설정을 받은 뒤에만**(`settingsDoc().confirmed`):
옛 사본 위에서 받으면 다른 기기 것을 덮는다. 부르는 곳: `afterPlain`(열 때), 날이 바뀔 때, 과목 줄을
고칠 때. 주말에는 다음 주를 받는다. 받으면 토스트 "이번 주 시간표를 나이스에서 받았습니다".
못 받으면 조용히 넘어가고 그날은 다시 묻지 않는다. 손으로 고친 칸은 다음 날 덮인다.
**시간표 탭 정리**(직접 찍어 확인):
- 종 시간 칸 `type=time` 은 좁으면 "오전" 만 보이고 시각이 잘렸다 → `hmIn` 글칸 `08:50 ~ 09:35`.
- 시정: 이름 위, 칸 아래, 단위 옆(`setField`). 「채우기」 → 「시간 채우기」 보조 단추.
- 회색 칸 속 회색 칸 → 가는 줄 표 한 장(`table.tt-edit`). 반은 칠하고(`on`), 창체는 옅게(`cc`).
  폰에서는 줄이지 않고 옆으로 굴린다(좁은 칸 규칙보다 세게 썼다).
- `bellForm` 의 `/^d{1,2}:d{2}$/` 에 역슬래시가 빠져 1교시 시작 칸이 늘 08:50 으로 보이던 것도 고쳤다.
- 시험: `DUMP_TT=파일 npm test` 로 시간표 탭을 뜬다.
